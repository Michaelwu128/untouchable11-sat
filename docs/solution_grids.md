# Solution Grids

本文件列出 repo 中 7 組 SAT 解答對應的盤面。彩色總覽圖見 [`solutions.svg`](solutions.svg)。

- 每個數字 / 字母代表一塊拼圖的編號（`0`–`9`、`A` = 10），與 generate 腳本中 `pieces_raw` 的順序相同。
- `.` 為空格。
- 盤面由各資料夾中的 `solution_*.txt` 與 `placements*.txt` 對照而來，與執行 `show_*.py` 得到的配置相同（show 腳本在 `--no-color` 模式只以 `#` 表示，不顯示編號）。
- 整理 repo 時已逐一檢查：每組解答都恰好包含 11 塊不同的拼圖、共 66 格，且任兩塊拼圖之間沒有邊或角的接觸。
